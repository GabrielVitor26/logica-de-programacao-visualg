# Exercícios de Lógica de Programação — Apostila Faccat

Repositório destinado ao armazenamento das resoluções dos **38 exercícios de algoritmos** desenvolvidos a partir da apostila da **Faccat**, utilizando a ferramenta **VisualG**.

## 📌 Sobre o Projeto
Este repositório faz parte das atividades práticas do curso de **Desenvolvimento Web e Programação** do **Instituto PROA**, com o objetivo de aperfeiçoar os conceitos fundamentais de lógica de programação, estruturas condicionais e de repetição.

## 📂 Estrutura dos Arquivos
Os exercícios estão identificados pelo número correspondente na apostila:
* `exercicio-01.alg` até `exercicio-38.alg`

## 🚀 Como Executar
1. Baixe e instale o [VisualG](http://visualg3.com.br/).
2. Abra o arquivo `.alg` desejado na ferramenta.
3. Pressione a tecla **F9** para executar o algoritmo.
